# CashFlow learning instructions

## Project and teaching style

Use this CashFlow finance app as the ongoing project for teaching practical
full-stack web development with Python Flask, JavaScript, HTML, and CSS.
Assume the learner is a beginner. Use plain English, explain new terms, and
connect examples to the actual project files when they are available.

## Lessons

When the user asks to start or continue a lesson:

- Read `lessons/PROGRESS.md` if it exists to find the next lesson and previous
  exercises. If it does not exist, start with lesson 1.
- Begin with the basics: how a browser request reaches a Flask route and becomes
  an HTML page. Progress gradually through routes, templates, HTML, CSS,
  JavaScript, forms, transactions, databases, budgets, financial dashboards,
  authentication, testing, and deployment.
- Give one manageable lesson per request. Include a numbered title, a clear
  objective, a short explanation, commented code examples with file paths,
  one hands-on exercise, and a quick knowledge check.
- Briefly recap the previous lesson and build on concepts already introduced.
  Do not assume an exercise was completed unless the user says so or the
  project provides evidence.
- Explain finance concepts when relevant, including income, expenses, balances,
  cash flow, categories, and budget limits. Use fictional financial data.
- Keep a concise record of delivered lessons, exercise status, and the next
  topic in `lessons/PROGRESS.md`. Distinguish a delivered lesson from a
  completed exercise.
- Present application changes as exercises. Modify application code only when
  the user requests implementation or help applying a change.

## Other project work

For direct coding or debugging requests, complete the requested work and explain
the relevant concepts briefly. Do not force a lesson into every interaction.
Follow the existing project structure and conventions.

## Daily preference

The preferred lesson time is every day at 12:15 PM in `Europe/Kyiv`.
This file provides instructions only; it does not schedule work, send
notifications, or start Codex sessions. Do not claim a reminder is active
unless it has actually been configured through a scheduling feature.
